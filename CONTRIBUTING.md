# Contributing to Folkhero

The project is currently in pre-production.

## Before changing implementation

Read AGENTS.md and the relevant documents in Docs/.

## Change scope

Keep changes focused.

Do not combine:
- a gameplay feature;
- broad architecture refactor;
- mass asset generation;
- unrelated cleanup;

in the same change unless there is a strong reason.

## Pull requests

Implementation PRs should include:
- intent;
- important design/technical choices;
- how the change was tested;
- evidence when useful;
- known limitations;
- documentation/skill updates.

## Documentation

Update source-of-truth docs when a decision changes.

Do not let important decisions exist only in chat.

## AI-generated work

AI-generated code/assets are held to the same acceptance standard as human-generated work.

"Generated successfully" is not a test result.
