# Experiments

This directory is for bounded prototypes and benchmark records that are not yet production systems.

Each experiment should state:
- question;
- hypothesis;
- setup;
- success criteria;
- result;
- decision;
- lessons.

Examples:
- Combat feel comparison;
- Ability architecture spike;
- Unity MCP benchmark;
- Generated creature pipeline benchmark;
- Enemy #1/#2/#3 production time;
- 100-enemy performance test;
- networking spike.

Failed experiments are valuable when documented.
