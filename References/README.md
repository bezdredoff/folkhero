# References

Store or link approved references here by category.

Suggested structure once assets exist:
- Gameplay
- Characters
- Creatures
- Environments
- VFX
- UI
- Animation
- Audio

References should distinguish:
- inspiration;
- target;
- anti-reference.

An anti-reference is useful when the team knows what it does not want.

Do not treat unreviewed AI generations as approved art direction.
