# Checklists

Short checklists belong here when they are useful across many skills.

## Content acceptance checklist

- fits approved fantasy and gameplay role;
- uses existing primitives where practical;
- no unnecessary bespoke system;
- references are valid;
- no unexpected console errors;
- testable in appropriate playground;
- feedback/readability reviewed;
- performance implications considered;
- relevant docs/skill updated;
- benchmark metrics recorded if this is a benchmark item.

## AI implementation review

- task scope was bounded;
- assumptions were stated;
- implementation compiles;
- automated tests were run where applicable;
- Play Mode evidence was inspected;
- no unrelated refactor was bundled;
- limitations were reported;
- no major design decision was silently changed.

## Generated asset review

- silhouette matches approved concept;
- proportions read correctly at gameplay distance;
- topology is appropriate for intended use;
- UV/materials are usable;
- functional parts are separated where needed;
- rig deforms acceptably;
- animation imports correctly;
- texture/material cost is acceptable;
- licensing/provenance requirements are satisfied.
