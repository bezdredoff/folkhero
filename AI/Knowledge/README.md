# AI Knowledge

This directory stores durable project knowledge that does not belong in a formal design bible or a repeatable skill.

Good examples:
- discovered Unity package incompatibilities;
- naming conventions learned during production;
- known limitations of a generation model;
- benchmark results;
- recurring art import pitfalls;
- useful project-specific technical facts.

Do not duplicate source-of-truth design decisions here.

If a fact changes product direction, update the appropriate Bible or Decision record instead.
