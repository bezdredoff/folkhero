# Производственные показатели

В рамках проекта необходимо определить, действительно ли АИ и системы многократного использования дешевле делают производство.

## Базовый показатель производства содержания

Для каждой контрольной позиции:

| Полевая | Значит |
| --- | --- |
| Пункт | Вражеский модуль/способность/VFX/встреча/биоме |
| Время человека | активных человеческих усилий |
| Время работы агента | приблизительное время исполнения |
| Стоимость API | Оплата расходов на производство/переработку |
| Попытки | Количество значимых итераций |
| Повторная работа | ручная коррекция |
| Новый код | требуется новый код рабочего времени |
| Повторное использование примитивных веществ | существующие системы повторного использования |
| Принята | Да/нет |
| Дефекты | Обнаружены позднее регрессии |
| Уроки | :: ссылки на обновленные данные о квалификации/знаниях |

## Основное производство КПУ

Дорожка во времени:
- время для создания новой способности;
- время для создания нового врага;
- время для новой встречи;
- процентная доля систем повторного использования;
- b) код на содержание;
- :: коэффициент принятия целевых заданий агента;
- время коррекции человека;
- - коэффициент регрессии;
- - стоимость в расчете на один из принятых активов;
- Время от утверждения концепции до результата, поддающегося воспроизведению.

## Устный перевод

Значительный объем производимого контента сам по себе не является успехом.

Предупреждающие знаки:
- каждый новый враг предпринимает такие же усилия;
- повторяющиеся одноразовые сценарии;
- - быстрый рост числа жучков;
- агенты часто нуждаются в полной переписке;
- с каждым параметром увеличивается время, необходимое для проведения обзора;
- :: создание разнообразия выглядит большим на бумаге, но сходится в выборе игроков.

Позитивные знаки:
- многократное содержание становится существенно более быстрым;
- в новом содержании используются главным образом данные/композиции;
- - ранние испытания на регрессию улова;
- :: старые системы приобретают ценность, когда добавляются новые системы;
- С течением времени коррекция агента становится меньше.
