# Журнал решения

Этот файл фиксирует высокоэффективные решения о продукте, поэтому они существуют не только в чате.

## 2026-10-17 — Пропуск на замок

### Жанр/прогресс
**Решение:**Folkhero () — системная совместная операция RPG / взлом и вспышка с постоянным продвижением.

**Отклоненное направление:**первичная рогулитная/перезапущенная конструкция.

### Первоначальные классы
**Решение:**Начните с двух основных архетипов:
- Воин;
- Ведун.

Будущие классы выходят за рамки нынешних.

### Боевое оружие
**Решение:**Семьи первоначального оружия - это топор и копье.

Рогатина и скайт/борьба с цитом сохранены для последующих вариаций.

### Контроль квалификации
**Решение:**Базовое нападение + до 4 активных навыков.

Начальная модель ресурсов класса является только охлаждением.

Поначалу никаких манов/стамина/крас.

### Универсальный уклон
**Решение:**Никакого универсального требования в отношении уклона/проката.

Мобильность/оборона могут обеспечиваться классом/оружием/навыками.

### Physicalповреждение
**Решение:** Physical- неразделимый тип повреждений.

Не разделяйтесь на резьбу/птичку/бросок.

### Базовый статус/системный набор
**Решение:**
- Wet;
- Fire/Burning;
- Cold/Frozen;
- Shock/Lightning;
- Poison;
- Curse.

Кровотечение откладывается.

### Первоначальные реакции
**Решение:**
- Wet + Cold -> Frozen;
- Wet + Lightning- > сильнееShock/Грузовое устройство;
- Wet + Fire- &quot; подавить/заглушить &quot;
- Wet + Poison- >загрязненная вода/распыление;
- Frozen+ Тяжелый ->Shatter;
- Curseможет изменять/составлять с любым основным направлением.

### Окружающая среда
**Решение:**Ограниченные, но важные системные поверхности:
- вода/влажная земля;
- снег/снег;
- огонь;
- Отравленная вода.

Погода существенно меняет боевые действия.

### Погода
**Решение:**Дождь, тепло, холод, метель/глубокий снег и туман являются модификациями геймплея, а не только визуальными.

### Модель орнамента
**Решение:**Гибридная модель получения знаний.

Найдите/ научитесь украшению один раз -> оно становится постоянным знанием -> Общинный ремесленник может использовать его для получения ресурсов.

### Места для размножения
**Решение:**Исходный показатель: одно первичное украшение на единицу оборудования.

Возможное исключение из правила о двойной ординатуре в редких/уникальных случаях позднее.

### Общие показатели по бесконечности
**Решение:**Связи с украшениями резюмируются по всему оснащенному зданию.

Пороговые значения могут изменить поведение/тип навыков.

### Строить специализацию
**Решение:**Базовое строительство поддерживает одну первичную и одну вторичную близость.

Будущие классы магии могут намеренно нарушить это правило.

### Продолжительность жизни
**Решение:**Оружие является долгоживущими платформами и может оставаться полезным для большей части игры.

Избегайте постоянной замены стойки.

### Рарность
**Решение:**Использовать меньше ярусов rarity, поскольку хищение является менее частым/более значимым.

Точное название остается открытым.

### Пересадка
**Решение:**Случайные действия:
1. применение/изменение украшения;
2. обновление базовых статистических данных;
3. редкое специальное изменение.

Приоритетом в области осуществления является сначала украшение, затем обновление, а затем специальная модификация.

### Инвентарные запасы
**Решение:**Минимальное искажение запасов; раздельная библиотека украшений; общий тайник.

### Экономика
**Решение:**1 нормальная валюта, 1-2 общие материалы, немного редких региональных/фольклорных материалов.

### Грабительская деятельность/сельское хозяйство
**Решение:**Наилучшее вознаграждение часто получают начальники/находки/подземелья/разведки/события, но при этом преднамеренно поддерживается повторяемое земледелие в подземельях и в пустыне.

### Процедурное поколение
**Решение:**Используйте философию, похожую на "Путь изгнания":
Авторские модули + сборка, основанная на правилах + авторские якоря + процедурный маршрут/встреча/выбор/погодное изменение.

### Категории врагов
**Решение:**Четыре основные категории содержания:
1. - люди;
2. нейтральные/территориальные духи;
3. по своей сути опасные сверхъестественные существа;
4. Проклятые/поврежденные существа.

### Число боссов
**Решение:**Первая цель игры ~ 10-12 боссов.

По крайней мере по одному главному рекордному боссу за один акт плюс выбранным боссам по бокам/подземельям.

### Правила о статусе босса
**Решение:**Боссы участвуют в одной и той же системе определения статуса/реакции.

Твердые карты борьбы с толпой с целью обеспечения безопасности босса, а не широкого иммунитета.

### Защита
**Решение:** ArmorдляPhysicalплюс индивидуальныеFire/Cold/Lightning/Poison/CurseСопротивление.

### Исцеление
**Решение:**Ограниченные заряды за исцеление, безопасное восстановление, позднее заживление на основе строительства.

### Смерть
**Решение:**Умеренный штраф на контрольно-пропускном пункте; сохранение уровня/оборудование; потеря некоторых временных ресурсов; частичное восстановление противника.

### Совместная операцияDowned
**Решение:** Downed/ Возвращайся до полной пересадки.

### Камера
**Решение:**Фиксированная/ограниченная ротация 3D сверху вниз/изометрическая камера с контролируемым увеличением.

### Направление искусства
**Решение:**Преднамеренно стилизован, частично выбранный для производства при помощи АИ/модуля/процедуры и подвижной масштабируемости.

### Мировая структура
**Решение:**Первая полная цель игры:
- 3 основных региона многократного использования;
- 5 актов;
- ~ 8-10 часов обязательной истории;
- ~12-15 часов, как правило, первый матч.

### Основная структура поиска
**Решение:**Стационарный сюжет + переменный маршрут.

### Последствия
**Решение:**Средние системные последствия с местным, региональным и небольшим числом решений (~3-5) на уровне кампании.

### Настройка описания
**Решение:**Альтернативная история опоздала GDL / Ранняя PLC, используя Ливонскую войну как исторический скелет.

Могут использоваться настоящие исторические названия/события.

### Подстрекательство к инциденту
**Решение:**Весенний ритуал в Марш поддерживает соглашение с местным болотником.

### Военная программа
**Решение:**Высшее руководство знает, что сверхъестественное является реальным, а санкции направлены на преднамеренное военное использование; специальная военная организация проводит операции.

### Дом/перемещение
**Решение:**Дом не разрушен, он становится политически недоступным.

Перемещенная деревенская община является периодическим центром/социальным якорем.

### Возвращение домой
**Решение:**Только два основных маршрута:
1. - защита/патронация с влиятельных сторон;
2. серые политические перемены, которые делают возможным возвращение.

### Спутники
**Решение:**Нет постоянной контролируемой системы компаньонов.

Разрешается оказание временной поддержки НПК.

### Центры
**Решение:**Та же самая основная община перемещенных лиц вновь появляется при изменении региональных узлов.

### Платформа
**Решение:**PC-первая разработка/Early Access; архитектура мобильных программ; iOS/Android позже.

### Обязательства по совместным операциям
**Решение:**В первом случае требуется совместная операция.Early Access- высвобождение и должно быть подтверждено в ближайшее время.

Долгосрочная цель 1-4; первоначальное фокусное соло + 2-плеер.

### Ответственность за проведение совместных кампаний
**Решение:**Развитие персонажей принадлежит каждому игроку; квест/общий прогресс-состояние принадлежит хозяину.

### Early AccessСфера применения
**Решение:**Одного региона достаточно для первого ЕА, если он доказывает сезонное/погодное/системное повторное использование.

Первый EA включает полный Закон I с ~2—3 часа главной истории плюс содержимое боковой/фермерской/повторной игры.

### Монетизация
**Решение:**Покупка премиум на игру.

Никакая продажа энергии, украшений, добычи, энергии или ускорения движения.

### Vertical Slice
**Решение:**20-30-минутный отрезок:
- Воин + Ведун;
- соло + 2-плеера коопирования;
- основной удар + 2 навыки/класс;
- основные характеристики/реакции;
- пороговые значения для украшений;
- значимая погода;
- :: процедурные вопросы, касающиеся лесов/водорослей;
- автор &lt; &lt; якорь &gt; &gt; квеста;
- нормальные враги + элита + босс;
- Downed/ Возвращение;
- - общинный мини-хуб ВСНП;
- - замена вознаграждения/строительства;
- Осмысленная повторная игра.
