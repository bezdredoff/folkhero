## Принцип развития

Каждая фаза устраняет разный риск.

Проект должен доказать, что**завод по производству игр**до масштабирования содержания.

# Ворота А — готовыVertical Slice

Требуются:
- перспективные примитивные бои;
- b) наличие двухпользовательских сетей, доказавших свою эффективность на уровне основных ресурсов;
- Фрагментальная реакция на сердцевую реакцию;
- - изменение пороговых значений для украшений;
- b) изменение погоды;
- :: процедура проведения региональных собраний является последовательной;
- - измеряют ускорение производства;
- не зависит от непроверенной одноразовой архитектуры.

# Vertical Slice

Целевая продолжительность:**20-30 минут**.

Требуются:
- Воин;
- Ведун;
- соло;
- 2 игрока;
- основной удар + 2 навыки на класс;
- Physical+ шесть основных семей/системных семей;
- не менее 3-4 значимых реакций;
- - пороговые значения размеров украшений;
- :: боестолкновения с применением дождя или снега, которые существенно изменяют ситуацию;
- - небольшие районные лесонасаждения/зоны погони;
- один автор квест-ведущий;
- несколько обычных врагов;
- одна элита;
- один босс, использующий реакции, безопасные для босса;
- Downed/ Возвращение;
- - одно знакомое общинное отделение НПК в мини-хубе;
- поощрение + обмен украшениями;
- значимый второй проигрыватель с другим строем/погодным состоянием.

Успех:
- второй этап является интересным по системным причинам;
- Воин и Ведун чувствуют себя различающимися.
- Кооп добавляет взаимодействие, а не только больше ущерба;
- архитектура выживает после роста контента;
- Дополнительные расходы на содержание становятся все более предсказуемыми.

# Расширение после проведения кампании по оказанию помощи в целях развития

Выращивайся к первой полной цели кампании:
- 3 региона;
- 5 актов;
- 8-10 часов в обязательном порядке;
- около 12-15 часов обычного первого проигрыша;
- приблизительно 10-12 начальников;
- около 15-20 основных квестов;
- системные последствия на местном/региональном/кампайне.

Добавить новые регионы/действия только в том случае, если завод по производству материалов обеспечивает их устойчивость.

# Долгосрочная поддержка/расширение

Проект может продолжаться в течение нескольких лет.

В идеале в новые главы/расширения следует добавить:
- b) новая системная переменная или взаимодействие;
- новая вражеская семья;
- новый начальник;
- новые украшения/строительные возможности;
- новый регион/государство;
- новые комбинации поиска/изобретения.

Предпочитать добавления, которые также ремиксируют старое содержание.

Модель работы:
- b) премиальные базовые игры;
- - существенное увеличение оплаты труда;
- - факультативная косметика, если она полезна;
- нет продажи электроэнергии/прогресса.

## Комплектная дисциплина

Не расширяться до:
- - доказан много классов до Ведуна и Ведуна;
- - многие регионы до начала работы первого регионального завода;
- - сложные работы по изготовлению украшений;
- - глубинные лестницы, обеспечивающие редкость предметов;
- - крупные системы контрагентов;
- - гигантские города с ручным трудом;
- :: создание сетей было отложено до позднего производства.
