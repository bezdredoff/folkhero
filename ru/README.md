# Folkhero — русская документация

> [!NOTE]
> Русское зеркало документации будет автоматически сгенерировано GitHub Actions после merge этой автоматизации.
>
> Для перевода используется локальная open-source модель Helsinki-NLP/opus-mt-en-ru на бесплатном GitHub-hosted runner. API-ключ и платный сервис перевода не требуются.
>
> Каноническая версия пока доступна здесь: [README.md](../README.md).

Автоматизация переводит README.md и все Markdown-файлы из Docs/ в зеркальную структуру ru/.

Подробности настройки: [Documentation Translation](../Docs/Production/Documentation_Translation.md).
