## Stages
Research -> Discussion-ready -> Brief-approved -> Exploration -> Selected -> Modeling-ready -> Implemented/validated.
Blocked and Rework may occur at any stage. Parent boards and child objects have separate states.
A registered task has not automatically passed research. Discussion-ready means evidence and uncertainty are explicit, not that every historical question is solved.

## Approved visual target manifest
Store actual selected assets under References/Targets/<target-id>/ with:
image path (or stable external artifact URL), SHA-256 when local, original native dimensions, generation/edit provenance, approval message/date, exact approved aspects and known defects.
Use separate targets for rendering language, house construction, human proportions, palette and effects.
A chat-approved image becomes a repository target only when the actual image is retrieved and identified. Until then mark TARGET-MISSING; the written art direction remains valid.
Do not label an image historically authoritative because its rendering style was accepted.

Before generating it: approved brief, available visual target or explicit style-exploration label, object IDs/scale, source constraints and review question.
Before modeling: selected coherent geometry and complete modeling packet.
Before broad production: human selection and benchmarks under AGENTS.md.
