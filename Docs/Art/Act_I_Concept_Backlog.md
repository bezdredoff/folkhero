# Act I Art Concept Backlog

Status: v0.2 — concept-production plan for Act I / Upper Berezina.

Track readiness/output in [Concept Register](Concept_Register.md). Apply [Asset Sheet Standard](Asset_Sheet_Standard.md), [Concept Readiness](Concept_Readiness.md) and [Evidence Dossier](../../References/Act_I_Evidence_Dossier.md).

These 60 tasks are family/system/composition briefs, not 60 finished object sheets. Each selected modeled object gets a child ID and separate modeling packet. P0 means important to core production or the slice, not that all P0 art must be finished before placeholder gameplay.

## Goal

Act I must prove that a compact art kit supports:
- home village and community;
- forest travel;
- meadow/pasture transition;
- wetlands/swamp;
- ritual spring;
- authority conflict;
- pact destruction/corruption;
- weather and seasons;
- status/reaction combat;
- normal, elite and boss encounters;
- displaced-community continuity.

Priority:
- **P0** — blocks Vertical Slice / core art production;
- **P1** — needed for full Act I;
- **P2** — polish/expansion.

## Definition of done

A concept is done only when:
- source assumptions are documented;
- reusable geometry is obvious;
- module swaps are obvious;
- material/state changes are obvious;
- gameplay-scale readability is shown;
- detail level fits mobile/systemic production;
- implementation in Unity is plausible.
