# Act I Art Concept Backlog

Status: v0.1 — concept-production plan for Act I / Upper Berezina.

## Goal

Act I must prove that a compact art kit supports:
- home village and community;
- forest travel;
- meadow/pasture transition;
- wetlands/swamp;
- ritual spring;
- authority conflict;
- pact destruction/corruption;
- weather and seasons;
- status/reaction combat;
- normal, elite and boss encounters;
- displaced-community continuity.

Priority:
- **P0** — blocks Vertical Slice / core art production;
- **P1** — needed for full Act I;
- **P2** — polish/expansion.

## Definition of done

A concept is done only when:
- source assumptions are documented;
- reusable geometry is obvious;
- module swaps are obvious;
- material/state changes are obvious;
- gameplay-scale readability is shown;
- detail level fits mobile/systemic production;
- implementation in Unity is plausible.
