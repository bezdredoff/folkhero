# Decision Log

Use this directory for consequential decisions that future developers/agents may otherwise reopen without context.

## Decision record template

# DEC-XXX — Title

Date:
Status: proposed / accepted / superseded

## Context
What problem or uncertainty existed.

## Decision
What was chosen.

## Alternatives considered
Important alternatives.

## Consequences
Benefits, constraints and known risks.

## Revisit when
Conditions that justify reopening the decision.

## Candidate early decisions

Create records when these are actually resolved:
- multiplayer commitment;
- networking stack;
- first hero archetype;
- first biome;
- procedural generation strategy;
- save architecture;
- telemetry provider;
- exact Unity MCP/tooling;
- asset versioning/LFS strategy.
